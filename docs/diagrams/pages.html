Pages & UI standards

Navigation maps, low-fidelity page sketches, and the shared rules for toasts, forms, dialogs and errors. Bootstrap pages are Twig + jQuery. Vue pages are Vue 3 + PrimeVue + Tailwind. The sketches show layout and content, not the final visual design. Colours follow the store's own branding (here: MyOil's Auto).

2. Form fields and validation

name@example.com
Default
jan@
Focused (no error yet while typing)
jan@
Enter a full email address, e.g. jan@example.com.
jan@garage-devries.nl
Fixed: the red disappears straight away
  • Invalid field: red border + icon + short message directly under the field that says what to do.
  • When checked: on blur and on submit. After the first error, it is re-checked while typing.
  • Required fields are marked *. Optional ones say "(optional)" when most fields are required.
  • After submit: focus and scroll to the first invalid field. Long forms (registration, checkout) also show an error summary with links to the fields.
  • The server is the source of truth (Symfony Validator). The client repeats only simple checks. Server violations are mapped onto the same fields.
  • Submit button: shows a spinner and is disabled while sending, so a form can't be submitted twice.
  • Bootstrap: bootstrap_5_layout form theme → .is-invalid + .invalid-feedback. Vue: a shared <FormField> component using PrimeVue invalid + <Message size="small" severity="error">.

3. Confirmation dialog (all destructive actions)

Cancel order AUTO-000124?
The customer's payment of €67.86 will be refunded and the stock will be released. This can't be undone.
Keep orderCancel order
  • It is required for every destructive action: delete, cancel, refund, remove, deactivate, revoke access.
  • Title = action + object ("Delete address 'Workshop'?"). Body = the consequence in one or two sentences.
  • Buttons: the safe choice on the left ("Keep …"). The destructive button on the right, in red, labelled with the verb (never just "OK").
  • Esc, clicking outside and all choose the safe option. Focus starts on the safe button.
  • For severe platform actions (deactivating a store, deleting a staff user), the user must type the name to confirm.
  • Bootstrap: one reusable modal + confirmAction({title, body, confirmLabel}), which returns a Promise. Vue: PrimeVue ConfirmDialog + useConfirmAction() with the same options.

4. Unsaved changes guard

Leave without saving?
You have unsaved changes on this page. If you leave now, they will be lost.
Stay on pageLeave without saving
  • It is active on every edit form: admin edit screens, account profile and addresses, checkout address step, contact form.
  • A form becomes "dirty" when a value differs from what was loaded, and becomes clean again after a successful save or when the change is reverted.
  • It catches in-app navigation (links, menu, back button in the SPA, store switcher) with the standard dialog.
  • Closing or reloading the tab uses the browser's own beforeunload dialog. Browsers don't allow custom text there, and that can't be changed.
  • Vue: useUnsavedChanges(isDirty) → onBeforeRouteLeave + beforeunload. Bootstrap: <form data-unsaved-guard> + jQuery link interception + beforeunload.

5. Icons

success info warning error delete edit add search cart account document shipping loading
  • No emojis anywhere in the UI, templates, emails or translation strings.
  • One icon library: Lucide (ISC license, SVG). Vue: lucide-vue-next. Twig: symfony/ux-icons → {{ ux_icon('lucide:circle-check') }}, rendered inline and locked into the repo with ux:icons:lock.
  • PrimeVue's built-in PrimeIcons are replaced by Lucide inside our wrapper components (toast, dialog, paginator…), and the primeicons font is not loaded.
  • One semantic icon map (success → circle-check, delete → trash-2…) is shared by both stacks, so the same action always has the same icon.
  • Icon-only buttons always have an aria-label. Decorative icons get aria-hidden="true".

6. Loading and empty states

Loading (skeleton)
Saving… button spinner, disabled
No orders yet
When you place an order, it will appear here.
Browse catalog
  • Page content: skeleton placeholders in the shape of the content, not a full-page spinner.
  • Actions: a spinner on the clicked button, which is disabled until the response arrives.
  • Loading shorter than 300 ms shows no skeleton, to avoid flicker.
  • Empty state: icon + one-line title + one explanation line + one action.
  • Empty search or filter result: "No products match these filters" + a "Clear filters" button.
